`security/DPIA-PREASSESSMENT.md`) when a release adds or changes code that
handles personal data. The org PII scan looks for a file in those
directories that mentions "DPIA". A release is never blocked by the scan; it
is flagged until a human reviewer confirms this pre-assessment is done.
