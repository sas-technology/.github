# Support

Looking for help with something in an `sas-technology` repository?

- **Bug or broken behavior** → open an issue in that repository using
  the Bug Report template.
- **New feature or change request** → open an issue using the Feature
  Request template.
- **"How do I…" / usage question** → check the repository's own
  `README.md` first; if that doesn't answer it, open an issue and tag
  it `question`, or reach out to the SAS Technology team directly.
- **Security or data-handling concern** → do **not** open a public
  issue. Follow [`SECURITY.md`](./SECURITY.md) instead.

If you're internal SAS staff and unsure which repo or who owns
something, ask in the SAS Technology team channel before filing
anything.
